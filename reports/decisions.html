What this report shows

Pilot work surfaced several concrete choices about how to configure non-biology pipeline components — thresholding methods, QC scope, scoring granularity, crop encoding, run size. Each card below lists the options actually tried for one decision, what happened with each, and which one the pipeline uses today. "Pending" means the current default is in use but the validation plan.md calls for has not been run yet. Full write-ups live in plan.md; the segmentation-threshold decision also has its own chart report, segmentation_check.html.
