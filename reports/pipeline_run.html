What this report shows

This page describes how the pipeline run itself went: how many cells came through each stage, how long each Slurm stage took, whether the built-in QC checks passed, how many cells coSMicQC flagged as segmentation outliers, and how many cells the CellProfiler/MorphEm fusion step kept. It does not say anything about the biology — see the phenotypic overview and buscar reversal reports for that.
